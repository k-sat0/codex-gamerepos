# This Can Can Can Cans

缶が缶を缶詰にする、見下ろし型アクション × インクリメンタルゲーム。設計書v1.0のMVPを実装しています。時間制限、ダメージ、ゲームオーバーはありません。

## 起動

公開URL：`https://k-sat0.github.io/codex-gamerepos/apps/this-can-can/`。GitHub Pagesの既存の配信設定を使います。

ローカルではリポジトリのルートを静的HTTPサーバーで配信します。依存ライブラリ、npm、ビルド、サーバー側APIは不要です。

Nodeがある環境では付属のプレビュー用サーバーを実行できます。`http://127.0.0.1:8000/apps/this-can-can/` を開き、終了するときは Ctrl+C を押します。

```sh
node apps/this-can-can/serve.cjs
```

Pythonがある環境では以下でも起動できます。

```sh
python -m http.server 8000
```

`http://localhost:8000/apps/this-can-can/` を開きます。ES Modulesのため、`file://` でHTMLを直接開く方法には対応しません。Node等の静的サーバーでも動作します。

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | フィールド下の方向ボタンを長押し |
| 狙う・吸引 | マウスで狙い、左ボタン長押し | フィールドの狙いたい位置を長押し |
| キーボードだけで吸引 | Spaceで吸引、Q / Eで左右に回転 | — |
| 一時停止・再開 | P / 一時停止ボタン | 一時停止ボタン |
| 強化 | ショップの購入ボタン | フィールド下のショップ。見出しで開閉可能 |

近くの缶を扇形の範囲に入れ、吸い込むとCANSになります。触れるだけでは捕獲できません。吸引と移動を同時に行えます。最初は15 CANSで「長い缶」が買えます。

今回の累積獲得が1,000 CANSで転生を解放します。`floor(cbrt(今回の累積 / 1000))` CAN DOを得て、今回の強化をリセット。報酬は1,000で1、8,000で2、27,000で3、10万で4、100万で10、1,000万で21、10億で100 CAN DOです。転生欄には次の報酬まで必要なCANSも表示します。

永久強化は次の5種類。研究所以外の価格は `2 + 2×現在Lv` CAN DO、軍資金だけ `1 + 2×現在Lv`。研究所は順に5・15・35 CAN DOです。報酬を平方根から立方根へ下げ、価格も上げることで、1回の転生で買い切らず少しずつ強化する調整です。初回の1 CAN DOで軍資金を購入できる導線を残しています。

| 永久強化 | 効果 | 上限 |
| --- | --- | --- |
| 缶の目利き | 獲得量 `×1.25^Lv`。今回の価値強化と乗算 | Lv.20 |
| 再出発の軍資金 | 開始資金 `150×Lv²` CANS。Lv.1=150、Lv.2=600、Lv.3=1,350 | Lv.20 |
| 吸引の才能 | 1Lvごとに射程+15px、吸引速度+20px/秒、扇形の広さ+6° | Lv.10 |
| 缶の呼び水 | 缶の密度 `×1.2^Lv`。「もっと缶！」と乗算 | Lv.10 |
| 缶の研究所 | 金缶→重量缶→磁石缶を解放。研究は転生しても残る | Lv.3 |

軍資金は購入直後にも前のレベルとの差額を支給するので、初回の転生後に買ってすぐ強化できます。次の転生では開始資金の全額で再出発します。支給分は今回/全期間の獲得統計に加算せず、軍資金だけで転生を繰り返すことはできません。Lv.1の150 CANSでは、価値強化以外の序盤5種（合計125 CANS）を買えます。

以前のセーブキーと購入レベルを維持しています。「生まれつきいい缶」は「缶の目利き」、「缶のへそくり」は「再出発の軍資金」に置き換わり、新しい2項目はLv.0で追加されます。所持金・永久通貨・実績はそのまま。旧軍資金レベルの新しい開始額は次の転生で適用され、読み込みだけで資金を追加することはありません。

## 成長・研究・実績

今回の「価値ある缶」は1Lvごとの倍率を×1.25から×1.15へさらに調整しました。Lv.10では×9.31から×4.05、Lv.20では×86.74から×16.37になります。価格は `ceil(100×2^現在Lv)` CANS（旧 `ceil(50×1.9^現在Lv)`）に上げ、初回50→100、Lv.10からの購入は30,656→102,400 CANSです。購入済みレベル・既存CANS・既存CAN DOを維持し、新しい効果と今後の購入・転生に新しい計算を適用します。永久強化の「缶の目利き」の効果は従来どおりです。

10万CANSは通過点になり、100万・1,000万・1億・10億CANSの実績と次の目標表示を追加。10億達成後も遊べます。「実績」タブで全15件の進捗と缶コレクションを確認できます。CANS実績は今回の獲得数が条件、転生実績は1・10・25回、収集実績は金缶25個・重量缶50個・磁石缶25個です。獲得した実績と収集数は転生後も残ります。

| 研究 | 特殊缶 | 新しく補充される缶の出現率 | 効果 |
| --- | --- | --- | --- |
| Lv.1 | 金缶 ★ | 4% | 報酬5倍 |
| Lv.2 | 重量缶 H | 8% | 報酬3倍、吸引速度45% |
| Lv.3 | 磁石缶 U | 5% | 捕獲地点から半径135pxの近い5缶を0.8秒引き寄せる |

研究すると今後の補充から特殊缶が出現します。購入前からフィールドにいる缶はそのままです。フィールド下に、研究済みの各特殊缶が現在何個いるか表示します。磁石缶は扇形の外の缶も引き寄せ、さらに磁石缶を捕まえると連鎖します。重量缶は連鎖中も吸引が遅いので、吸引の才能が役立ちます。色と記号で種類を区別します。コレクションは実体の捕獲数を数え、密度圧縮による代表缶数や報酬倍率は掛けません。

旧セーブには研究Lv.0を追加します。既存の通貨・購入・実績は保持し、過去に記録していなかった転生回数と種類別収集数は今回の更新から数えます。

## レア缶の図鑑・着替え

最初から、ふつう缶の約0.17%（合計0.17335%）がレア缶として出現します。研究で解放する金缶・重量缶・磁石缶とは別で、報酬と吸引性能はふつう缶と同じです。フィールドでは少し大きな缶・特別なラベル・ダイヤの枠が目印。色だけでなく記号でも区別できます。

| レア缶 | ラベル | ふつう缶に対する出現率 | 希少度 |
| --- | --- | --- | --- |
| サイダー缶 | S | 0.12% | レア |
| 桃缶 | P | 0.04% | レア |
| コーヒー缶 | B | 0.01% | レア |
| 星くず缶 | ✦ | 0.003% | スーパーレア |
| オーロラ缶 | A | 0.0003% | スーパーレア |
| 宇宙缶 | ∞ | 0.00005% | ウルトラレア |

従来より順に10・20・50・100・500・1,000倍出にくくしました。宇宙缶はふつう缶の約200万分の1です。既に発見した図鑑と着替えは維持します。確率表示は小数5桁まで表示し、最希少種も0%に丸めません。

「図鑑」タブは、未発見のヒント、発見後の名前・小さな物語・実体捕獲数、6種の完成度を表示します。初回捕獲は一度だけ登録通知して保存し、その缶の見た目を解放。「この缶で遊ぶ」でプレイヤーを着替えられ、いつもの缶にも戻せます。着替えで倍率や価格は変わりません。図鑑・捕獲数・選択した見た目は転生後も残ります。レア缶は通常分類の捕獲数にも含めます。

旧セーブに図鑑を空で追加し、通貨・強化・実績・設定を維持します。見た目の初期値は従来の缶。壊れた収集数は復旧し、未発見の見た目や未知のIDは選択できません。

設定で効果音・音量・粒子・画面のゆれを変更できます。音は既定でOFF。`prefers-reduced-motion` 有効時は初期演出を減らし、設定で粒子を戻しても揺れ・飛び込み・点滅する吸引線は抑制します。ウィンドウのフォーカスを失った場合は一時停止し、再開操作を待ちます。

フィールド下の「♪ 音OFF」で効果音をONにできます。設定の「♪ 捕獲音を試す」はON/OFFの設定を変えずに試聴できます。捕獲SEはC4のド（約261.6Hz）からC6のド（約1046.5Hz）まで、ドレミファソラシドの15音で上がります。経過時間による上昇を廃止し、連続して集めた缶8個分ごとに次の音へ、113個分で最高音になります。密度圧縮した代表缶数も含み、大量捕獲なら1フレームで最高音まで到達します。報酬倍率・缶の価値は音程に影響しません。1.2秒を超えて途切れると最初のドに戻ります。高音域では金属の高次倍音とノイズを減らし、ドの音程と低いオクターブの余韻を中心にした柔らかな音にしました。3個分以上の同時捕獲では厚みが増します。試聴は低いドから最高のドまでの5音です。50ms以内の捕獲は次の発音にまとめ、同時発音は5音まで。短いフェードとコンプレッサーで耳障りなピークを抑えます。Web Audio APIで合成するため音声ファイルや外部依存は不要です。

## 保存

- キー：`this-can-can-save-v1`。保存形式にも `version: 1` を含めます。
- プレイ開始時、10秒のプレイごと、購入、転生、設定変更、マイルストーン、ページ非表示・離脱時に保存します。
- 通貨、今回/全期間の累積、6種類の強化、永久通貨、永久強化、設定、実績、転生回数、種類別収集数、レア缶の図鑑・収集数・選択した見た目、プレイヤー位置を保持します。缶の位置は再生成します。
- 壊れたJSON、不正な数値、未知バージョンは安全な初期値へ復旧します。保存が使えない環境でもプレイでき、保存不可の表示を出します。
- データ削除は確認ダイアログ付き。他のゲームの記録や `asobi-theme-v1` は削除しません。
- オフライン収入はありません。ページ非表示時はシミュレーションを停止します。

## 構造と実装判断

```text
index.html        日本語UI、HUD、ショップ、設定・転生・削除ダイアログ
style.css         ../../theme.css を読み込む共通テーマ対応CSS
src/
  main.mjs        初期化、DOM更新、ダイアログ、保存タイミング、描画ループ
  engine.mjs      単一のGameState、移動、吸引、敵補充、経済、強化、転生
  renderer.mjs    Canvas 2D、追従カメラ、DPR・リサイズ、捕獲演出
  input.mjs       キーボード、ポインター、タッチ移動、入力の解除
  save.mjs        保存・復元・削除とエラー処理
  audio.mjs       SEの再生・音程の連続変化・試聴・発音数とピークの制限
  capture-sound.mjs  ポップ/金属/弾ける音/余韻のPCM合成
verify.mjs        Node標準assertによるゲームロジックの検証
serve.cjs         Node標準ライブラリだけのローカル静的プレビュー
```

- ES Modulesの拡張子を `.mjs` にし、ブラウザとNodeの検証で同じ処理を使用。package.jsonは不要です。
- リポジトリの共通指定を優先し、日本語UI、SODA POPのライト/ダーク、音OFF、スマホ操作を採用しました。画像や外部フォントは使わず、Canvas図形で缶を描きます。
- 敵は近辺を漂い、捕獲後すぐ補充。中心付近への突然の出現を避け、フィールド端でも一定の距離を確保します。遠すぎる敵は近辺へ再配置します。
- 密度は `ceil(25 * 1.25^level)`、実体は最大300個。超過時は `representedCount = target / 300` とし、捕獲報酬に掛けます。代表缶には「×」を表示します。
- カメラはワールド端で止まり、場外の空白を避けます。CSSピクセルをワールド座標に変換し、Canvasの実ピクセルはDPR（最大2）で管理します。
- 捕獲後に配列をまとめて削除するため、同時捕獲の判定漏れを防ぎます。粒子・数字は最大55件、効果音は50ms以上の間隔で集約します。
- DOM更新は約100ms間隔、描画はrequestAnimationFrame。時間差は最大50msで、獲得率はシミュレーション上の直近5秒の実測獲得額です。テーマ変更は色だけ更新し、ゲーム状態を保持します。
- 経済数値はJS Number、上限はNumber.MAX_SAFE_INTEGER。最大レベルまでの価格・倍率はこの範囲内です。超高倍率向けの大数表現は将来拡張です。
- モバイルのショップはフィールド下の開閉パネルにしました。フィールドを覆わず、上下スクロールで強化できます。
